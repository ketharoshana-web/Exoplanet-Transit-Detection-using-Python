# Exoplanet-Transit-Detection-using-Python
Predicting exoplanets from Kepler space telescope telemetry using custom signal processing and Machine Learning
Engineered a full-stack data pipeline to ingest and process raw telemetry from NASA's Kepler Space Telescope.

Applied digital signal processing techniques (filtering, phase folding) to isolate planetary transit anomalies within high-noise time-series data.

Developed a logistic regression perceptron classifier entirely from scratch using custom gradient descent optimization, bypassing standard pre-built libraries to demonstrate deep algorithmic comprehension.

Achieved [57.77 %] accuracy in classifying physical exoplanet transits versus false-positive stellar anomalies.
